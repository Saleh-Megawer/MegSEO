# Data Model: Twitter Card Check

## TwitterCardCheckInput
- `twitterCard`: twitter:card value
- `twitterTitle`: twitter:title value
- `twitterDescription`: twitter:description value
- `twitterImage`: twitter:image value
- `allProperties`: full associative array

## TwitterCardCheckMetadata
- `checkIdentifier` (`seo.twitter_card`)
- `twitterCardProvided`, `twitterTitleProvided`, etc.
- `validImageUrl`, `relativeImageUrl`
- `validCardType`
- `conflictingValuesDetected`
